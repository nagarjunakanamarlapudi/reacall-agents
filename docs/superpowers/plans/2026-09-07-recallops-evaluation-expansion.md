# RecallOps Evaluation Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add digest-verified retrieval ablations, orchestration comparisons, a unified offline scorecard, and synchronized UI/demo/diagram evidence proving what RecallOps techniques add.

**Architecture:** Preserve the existing R01–R21 safety evaluator unchanged, then add two independent deterministic suites: a 96-case retrieval benchmark over production retrieval components and a 24-case trajectory benchmark comparing a bounded single-agent baseline with fixed specialists. Build a signed-by-content scorecard from all three reports, project only validated summaries into Streamlit, and keep optional live Deep Agents/model judging outside the offline gate.

**Tech Stack:** Python 3.12, Pydantic 2, scikit-learn/NumPy, existing BM25/LSA/RRF retrieval, LangGraph/Deep Agents boundaries, Streamlit, pytest, Mermaid CLI, `uv`, Make, built-in image generation.

**Spec:** `docs/superpowers/specs/2026-09-07-recallops-evaluation-expansion-design.md`

## Global Constraints

- Preserve `data/evals/scenarios.json`, `data/evals/report.json`, and `uv run recallops eval --report data/evals/report.json` semantics.
- Default evaluation is deterministic, offline, credential-free, and read-only.
- Safety gates and zero-tolerance counters cannot be overridden by ranking metrics, a model judge, or a live Deep Agents result.
- Retrieval cases total exactly 96 in the 24/16/16/16/8/8/8 family distribution specified by the design.
- Orchestration cases total exactly 24 and run both credential-free profiles with no Operations capability.
- Every corpus/report/scorecard is canonical-JSON digest bound; missing or stale artifacts display unavailable, never zero or passed.
- Optional live-model runs report provider, model, prompt digest, token/cost availability, repetitions, and explicit unavailable/error status.
- No raw chain-of-thought, secret, real PII, or unmasked tool payload is stored or shown.
- Every production change follows RED→GREEN TDD and ends in a focused commit.
- Mermaid/SVG is technical truth; polished PNGs are presentation assets and must match implemented evaluation claims.

```python
def recall_at_k(relevance: Mapping[str, int], ranked_ids: Sequence[str], k: int) -> float:
    _validate_ranking(relevance, ranked_ids, k)
    relevant = {key for key, grade in relevance.items() if grade > 0}
    return 0.0 if not relevant else len(relevant & set(ranked_ids[:k])) / len(relevant)


def reciprocal_rank(relevance: Mapping[str, int], ranked_ids: Sequence[str]) -> float:
    _validate_ranking(relevance, ranked_ids, max(1, len(ranked_ids)))
    for rank, document_id in enumerate(ranked_ids, start=1):
        if relevance.get(document_id, 0) > 0:
            return 1.0 / rank
    return 0.0
```
